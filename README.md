# Colorini

Water sort **rogue-like** (HTML/CSS/JS).

## Spedizione

- Palette a **12 colori distinti**
- Mosse = **soluzione calcolata dal solver + 2** ( +3 al piano 1 )
- 1 vita; morte → piano 1 con inventario tenuto fino al clear
- Bottega di Travaso: gocce = mosse avanzate
  - **Reliquie** — passive, restano per tutta la run
  - **Oggetti** — consumabili, una sola volta

## Archivio

Livelli classici senza limite mosse.
